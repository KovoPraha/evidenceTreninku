# Předání vývoje na další stanici — 29. 8. 2026

Tento dokument je samostatný předávací bod. Autoritativní verze je commit na
`origin/main`, který obsahuje tento soubor, případně tag
`handoff-2026-08-29`. Přesný lokální commit ověříte příkazem `git rev-parse HEAD`.

## Co je v předání

- kompletní zdrojový kód jedné aplikace Evidence + e-shop + KIS,
- všech 70 číslovaných migrací a legacy baseline 2.20.2,
- bezpečnostní opravy datových zápisů, importů a soukromého úložiště,
- transakční koordinace databázových a souborových změn,
- offline Bootstrap 5.3.3, Bootstrap Icons a jejich licence,
- localhost seed se syntetickým rodičem, sportovcem a superadministrátorem se
  všemi osmi pracovními pozicemi,
- přenositelná první instalace čisté MariaDB bez osobních dat,
- zdrojový audit datových toků v XLSX a Markdownu,
- automatické testy a návody k intenzivnímu offline UAT.

## Co v GitHubu záměrně není

- `config.php` a jakékoli produkční tajemství,
- lokální datový adresář MariaDB a obnovovací SQL dumpy,
- produkční či historická osobní data,
- skutečné KIS/Shoptet importy, přílohy, outboxy a session,
- složka `vendor/`; obnoví ji `composer install` přesně podle `composer.lock`.

Tyto výjimky nejsou neúplnost předání, ale bezpečnostní hranice. Verzovaný
`database/local-demo-schema.sql` obsahuje pouze strukturu a setup ji naplní
výhradně syntetickými daty.

## Převzetí krok za krokem

```powershell
cd C:\xampp\htdocs
git clone https://github.com/KovoPraha/evidenceTreninku.git evidencePavel
cd evidencePavel
git checkout main
git pull --ff-only origin main
```

Potom dvojklikem spusťte `PRIPRAVIT_LOCALHOST_TESTOVANI.cmd`. Je potřeba XAMPP
s PHP 8.2+, MariaDB nástroji a Composer. První průchod může potřebovat internet
pro Composer; následné testování je offline. Skript:

1. vytvoří `C:\xampp\mysql\evidence-local-data`, pokud ještě neexistuje,
2. spustí ji izolovaně na `127.0.0.1:3308`,
3. vytvoří ignorovaný `config.php` z bezpečného vzoru,
4. importuje prázdné schéma bez aplikačních dat,
5. aplikuje migrace a verzovanou syntetickou Shoptet fixture,
6. idempotentně připraví kompletní localhost demo,
7. spustí Apache a ověří HTTP 200.

Při dalších startech stačí `START_LOCALHOST_TESTOVANI.cmd`.

## Syntetické přístupy

| Role | Přihlášení | Heslo |
|---|---|---|
| Administrátor | `localhost-admin` | `LocalhostAdmin123!` |
| Rodič | `rodic@localhost.test` | `Localhost123!` |
| Sportovec | `localhost-sportovec` | `LocalhostSportovec123!` |

Administrátor je superadmin, má všech osm pracovních pozic a výchozí pozici
`Správce systému`. Všechny účty a objednávkové údaje jsou lokální a syntetické.
Testovací QR je označeno `NEPLATIT` a používá neexistující bankovní kód `9999`.

## Ověření po převzetí

```powershell

composer check-platform-reqs
composer test
$env:APP_HOST='localhost'
php bin/migrate.php --check --json
```

Pro ruční UAT pokračujte podle
`outputs/localhost-test-2026-08-25/OFFLINE_TESTOVANI.md`. Audit datových vstupů,
větvení, úložišť a výstupů je v `outputs/data-flow-audit-2026-08-24/`.
Přesné výsledky automatických kontrol, čisté instalace a lokálního HTTP jsou v
`docs/VERIFICATION_2026-08-29.md`.

## Omezení a bezpečnostní hranice

- TinyMCE je volitelný CDN editor; offline se automaticky použije funkční
  textové pole.
- Stripe, Fio, skutečné e-maily, produkční cron a ostré KIS importy zůstávají
  vypnuté nebo fail-closed.
- Legacy přímé zapisovače závodů jsou ukončené a odkazují na kanonické cesty.
- KIS synchronizace je preview/sandbox; bez explicitní bezpečné propagace
  nemění kanonická data.
- Push tohoto předání na GitHub není produkční deploy. Produkci ani její data
  tento předávací krok nemění.

## Jak pokračovat ve vývoji

Před novou prací spusťte `git status --short`, pracujte z aktuálního
`origin/main` na větvi s prefixem `codex/` a nemíchejte do commitu `config.php`,
lokální importy ani databázové dumpy. Novou změnu uzavírejte testy, kontrolou
migrací a samostatným popisem případného produkčního nasazení.
