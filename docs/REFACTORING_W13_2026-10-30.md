# W13 — společné rozhraní a formuláře

Rozsah: sdílený shell již používají aplikační HTML stránky (inventurní test
SharedUiShellTest). Bez dalšího plošného přesouvání šablon či mazání assetů.
Konkrétní kandidát: automatické propojení starších administrátorských labelů
pro každý nový identifikátor znovu prohledává celý dokument. Zachovat stejné
ID, kolize, názvy a pořadí, nahradit opakované skeny jediným lokálním indexem.

Před změnou behaviorální RED na 1000 polích; po změně stejná jména a ID,
nejvýše jeden průchod existujícími ID. Prohlížeč: skutečný shell, lokální
assety, role návštěvník/rodina/sportovec/trenér, desktop a 390px mobil,
menu klávesnicí, escapování, názvy polí, chybový/prázdný stav a odeslání.
Syntetický shell není důkaz autentizovaného produkčního UAT všech obrazovek.
